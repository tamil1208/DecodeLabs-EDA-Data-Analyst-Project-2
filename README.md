## 🚀 Project Overview

This project was completed as part of the **DecodeLabs Data Analytics Industrial Training Program (Batch 2026)**.

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on a dataset to uncover meaningful insights, identify patterns, detect anomalies, and transform raw data into actionable information.

EDA serves as the foundation of every data-driven decision-making process.

---

## 🎯 Objectives

- Understand the structure of the dataset.
- Perform data cleaning and preprocessing.
- Analyze missing values.
- Generate descriptive statistics.
- Identify trends and distributions.
- Detect outliers using statistical methods.
- Explore relationships between variables.
- Summarize key findings and business insights.

## 📋 Exploratory Data Analysis Workflow

### 1. Data Collection
- Imported dataset from Excel/CSV files.
- Loaded data into Pandas DataFrame.

### 2. Data Cleaning
- Checked data types.
- Removed duplicates.
- Handled missing values.
- Corrected formatting issues.

### 3. Descriptive Statistics
Calculated:

- Mean
- Median
- Mode
- Count
- Standard Deviation
- Minimum
- Maximum
- Quartiles

---

### 4. Missing Value Analysis

Performed:

- Missing value count.
- Missing value percentage.
- Visualization of null values.

---

### 5. Distribution Analysis

Visualized data using:

- Histograms
- Density Plots
- Count Plots

Purpose:
- Understand data distribution.
- Detect skewness.

---

### 6. Outlier Detection

Methods used:

#### Boxplot Analysis
Used to identify extreme observations.

#### IQR Method

```
Lower Bound = Q1 − 1.5 × IQR
Upper Bound = Q3 + 1.5 × IQR
```

---

### 7. Correlation Analysis

Generated correlation heatmaps to identify relationships among numerical variables.

Techniques:

- Pearson Correlation
- Heatmap Visualization

---

### 8. Data Visualization

Created insightful visualizations including:

- Histograms
- Boxplots
- Scatter Plots
- Correlation Heatmaps
- Bar Charts
